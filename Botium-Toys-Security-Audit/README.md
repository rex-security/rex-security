# Botium Toys Security Audit

This project is a simulated internal security audit completed as part of the Google Cybersecurity Professional Certificate.

The assessment focused on identifying security risks, reviewing security controls, evaluating compliance requirements, and recommending improvements to strengthen Botium Toys' security posture.

## Areas Assessed

- Security controls
- Least privilege
- Separation of duties
- Password policies
- Encryption
- Intrusion detection
- Disaster recovery
- Asset classification
- PCI DSS
- NIST Cybersecurity Framework
